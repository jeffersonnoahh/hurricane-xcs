HURRICANE XCS

Widget dashboard di layar iPhone

Omzet hari ini, target, omzet bulan ini, top sales, dan grafik 14 hari — langsung di layar utama atau layar kunci. Hanya membaca data, tidak bisa mengubah apa pun.

Ketuk tombol hijau untuk menyalin script widget.
  1. Pasang aplikasi Scriptable (gratis) dari App Store. Buka Scriptable di App Store
  2. Ketuk tombol hijau di atas untuk menyalin script.
  3. Buka Scriptable, ketuk + di kanan atas, lalu tekan lama → Paste. Ketuk judul "Untitled Script" di atas, ganti jadi Hurricane, lalu Done.
  4. Di layar utama: tekan lama bagian kosong → Edit → Add Widget → cari Scriptable → pilih ukuran (kecil, sedang, atau besar).
  5. Tekan lama widget yang baru → Edit Widget → Script: pilih Hurricane. Biarkan "When Interacting" apa adanya — mengetuk widget membuka dashboard.
  6. Opsional, layar kunci: tekan lama layar kunci → Customize → Lock Screen → tambah widget Scriptable → pilih script Hurricane.

iOS memperbarui widget sendiri kira-kira tiap 10–15 menit. Jam kecil di pojok widget = terakhir diperbarui; tulisan "offline" berarti sedang tidak ada internet dan angka terakhir yang tampil.
